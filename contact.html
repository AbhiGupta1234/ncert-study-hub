Contact

Bug reports, feature ideas and questions are all welcome.

The fastest way to reach the developer is through the project's GitHub repository. You don't need to be a programmer to open an issue — a plain description of what happened is enough.

1. Report a bug or ask a question

Open an issue on GitHub and describe:

  • What you were doing when the problem happened.
  • What you expected vs. what actually happened.
  • Your device (Windows PC or Android phone) and app version (shown on the home screen of this site).

A GitHub account is required to post; it's free and takes a minute to create. Issues are public, so please don't paste passwords or personal information into them.

2. Feature requests

Ideas for new features are also filed as GitHub issues — use the same link above and start your title with "Suggestion:". Popular requests get priority.

3. Privacy-related questions

If your question relates to data or privacy, read the Privacy Policy first — it explains exactly where every type of data lives. If something is still unclear, mention "Privacy" in the issue title.

4. Response time

This is a free, independently developed project, so there are no fixed support hours — most issues receive a response within a few days.
